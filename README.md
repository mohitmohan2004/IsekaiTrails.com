# IsekaiTrails.com

Modern React + Vite travel/adventure website.

## Run
```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Pages
- Home
- Explore
- Destinations
- Trails
- Trip Planner
- Login
- Register

The current build uses responsive CSS and remote Unsplash imagery. Replace image URLs with local assets in `src/main.jsx` when you add your own photos.
